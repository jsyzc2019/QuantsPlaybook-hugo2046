# 从安装到完成一次指数择时回测

本教程从环境检查开始，运行中证500的 SAE（稀疏自编码器）研究 notebook，最后查看训练、预测、净值和分年绩效。无需 Hugo 的私有 DataFeed 模块。

## 第一步：安装并检查环境

需要 Python 3.10+。现有 notebook 使用 Python 3.13.11 成功运行过，这不是所有依赖版本组合的兼容性保证。以下终端命令从 QuantsPlaybook 仓库根目录开始；后续命令均在策略目录运行。

```bash
cd 'C-择时类/基于稀疏自编码器的指数择时'
python -m pip install -r requirements.txt
python -m pip install notebook ipykernel
python -c "import numpy, pandas, torch, talib, duckdb, sklearn; print('核心依赖导入成功')"
```

看到“核心依赖导入成功”即可继续。Jupyter 不在项目 requirements 中，因此单独安装。可使用自己已有的虚拟环境，所有安装和启动命令应使用同一个 Python。

## 第二步：配置数据源并看到首批行情

DataFeed 是 Hugo 私有的数据访问模块，不随本项目提供。没有该模块时，项目使用开源 `tushare` 客户端访问 TuShare Pro；客户端开源不表示所有数据接口都无需账号权限。

首次配置时，在策略目录复制模板；已有 `.env` 时直接编辑，不要覆盖：

```bash
cp -n .env.example .env
python -m notebook notebook/hy_sae_timing.ipynb
```

在编辑器中打开 `.env`，填写自己的 `TS_TOKEN` 后保存。不要把 token 写进 notebook 或输出日志。已有同名环境变量优先于 `.env`；可用的 DataFeed 优先于 TuShare 回退分支。

在页面中选择安装依赖的 Python 内核，从第一格代码顺序运行到 `index_df.tail()`。预期看到日期索引及 `open/high/low/close/preclose/volume/amount/turn` 八列。首次运行会联网创建行情缓存；随后相同覆盖区间可复用缓存。

默认数据库为策略目录下 `data/hy_sae_timing.duckdb`。原项目已有数据不分发，`data/` 与 `.env` 被 Git 忽略。若只查看 notebook 已保存的图表，不需要重新取数。

没有 DataFeed 的告警本身不代表失败；只有后续 TuShare 配置或调用也失败时才需要处理。具体错误见[常用操作与排查](常用操作_20260922.md)。

## 第三步：运行训练并读取结果

继续运行参数、特征和 `SAETimingGenerator(config).run(index_df)` 单元格。当前 notebook 使用中证500、2020–2025 样本外区间、10 个 seed（随机初始化种子），每年独立训练后平均预测；模块默认是 5 个 seed。

训练时会输出各年份的训练日数、预测日数和 seed 数量。结束后检查：

```python
print(result.folds[["year", "train_start", "train_end", "test_start", "test_end"]])
print(result.predictions.tail())
print(len(result.feature_names))
```

默认完整历史下应有六个测试年度、92 个特征，以及 `seed_0` 至 `seed_9` 和均值 `score` 列。实际日期以结果为准；请求从2005年开始不表示2005年就有可训练行情。

继续运行余下单元格，查看损失曲线、seed 相关性、阈值对比，以及多空、只做多、只做空净值和分年绩效。更改配置后，从取数或配置单元格开始重跑所有依赖单元格，避免旧变量与新配置混用。

## 如何理解结果

`score` 是未来累计收益率预测，不是上涨概率。信号取 −1、0、1，默认阈值0.2%；死区内维持之前信号。T日信号在T+1收盘成交，主回测使用 vectorbt 原生账户，零费用与滑点。

Notebook 分年绩效用几何年化收益/年化波动计算 Sharpe。`analyze.performance` 的 Sharpe 采用算术均值口径，两者不能混作同一个统计量。调用 `report_reference.annual_performance` 只是在计算统计量，并没有把原生账户净值改成研报倒数空头收益。

网络结构、特征配方和若干参数属于复现假设。运行成功不等于精确复现研报，单次结果也不能证明样本外稳定性。源项目[历史偏离评估](研报复现偏离评估_20260921.md)保留旧版本与实验记录，其中旧路径和未随项目提供的证据不能当成当前运行产物。

## 你完成了什么

你现在有本地行情缓存、内存中的训练结果和 notebook 图表。`run()` 不自动保存模型或实验结果；关闭内核会丢失内存变量，保存 notebook 只保留单元格与显示输出。
