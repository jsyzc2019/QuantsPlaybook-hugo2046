# 配置与新人常用接口参考

本文覆盖新人操作涉及的研究配置、模型配置、取数、训练与结果结构；存储层和底层算法的完整公共接口以 `src/` 文档字符串为准。操作示例见[常用操作](常用操作_20260922.md)，首次使用见[新人教程](使用指南_20260922.md)。

## ResearchConfig 全部字段

定义：`src.generator.ResearchConfig`，不可变 dataclass。以下是模块默认值；当前 notebook 唯一额外改变的训练集成数量是10个 seed。

| 字段 | 类型 | 模块默认 | 含义与约束 |
|---|---|---|---|
| `code` | `str` | `'000905.SH'` | 指数代码，仅标记结果；取数时也要传相同 code |
| `train_start` | `str` | `'2005-01-01'` | 最早候选训练日，须早于首个测试年年初 |
| `test_start` | `str` | `'2020-01-01'` | 样本外开始日；年中开始不会把同年早期行用于训练 |
| `test_end` | `str` | `'2025-12-31'` | 样本外结束日，不能早于开始日 |
| `horizon` | `int` | `5` | 未来累计收益周期，至少1个交易日 |
| `label_skip` | `int` | `1` | 成交相对信号日的偏移，非负 |
| `seeds` | `tuple[int, ...]` | `(0, 1, 2, 3, 4)` | 种子序列，不能为空或重复；notebook 显式使用0至9 |
| `feature_windows` | `tuple[int, ...]` | `(5, 10, 20, 60, 120, 250)` | 特征滚动窗口；决定预热长度 |
| `ma_pairs` | `tuple[tuple[int, int], ...]` | `((5, 10), (5, 20), (10, 20), (20, 60), (60, 120), (120, 250))` | 均线比值对，两端应在 feature_windows 中 |
| `rsi_form` | `str` | `'bounded'` | bounded 或 ratio；ratio 可能产生非有限值 |
| `wavelet_window` | `int` | `256` | 因果小波窗口，当前默认预热再消耗255行 |
| `wavelet` | `str` | `'db4'` | 小波基名称 |
| `wavelet_level` | `int` | `4` | 小波分解级数 |
| `wavelet_mode` | `str` | `'reflect'` | 小波边界延拓模式 |
| `threshold` | `float` | `0.002` | 迟滞阈值，非负，0.002即0.2% |
| `annual_days` | `int` | `252` | 年化日数，至少1；独立绩效调用还需显式传入 |
| `model` | `ModelConfig` | `ModelConfig()` | 模型与训练配置，见下表 |

日期和窗口约束还会在实际取数、特征构造及年度切分时校验；配置能构造成功不表示已有足够历史可训练。

## ModelConfig 全部字段

定义：`src.model.ModelConfig`，不可变 dataclass。网络宽度和损失权重是复现设定，不是研报完整披露的配方。

| 字段 | 类型 | 默认 | 含义与约束 |
|---|---|---|---|
| `hidden_dim` | `int` | `64` | 隐藏层宽度，正整数 |
| `code_dim` | `int` | `16` | 稀疏编码维数，正整数 |
| `epochs` | `int` | `100` | 固定训练轮数，正整数 |
| `batch_size` | `int` | `256` | 批大小，正整数 |
| `learning_rate` | `float` | `0.001` | 学习率，有限正数 |
| `reconstruction_weight` | `float` | `0.1` | 重构损失权重，有限非负数 |
| `sparsity_weight` | `float` | `0.1` | 稀疏损失权重，有限非负数 |
| `rho` | `float` | `0.05` | 目标平均激活率，有限且在(0,1)内 |

## 取数接口

```text
get_index_dataset(start_date, end_date, *, db_path=DEFAULT_DB_PATH,
                  code="000905.SH", turnover_policy="require", client=None)
load_index_dataset(db_path, start_date, end_date, *,
                   code="000905.SH", turnover_policy="require")
```

两者返回 `pandas.DataFrame`，索引为升序、无重复的 `DatetimeIndex`，列为 `open/high/low/close/preclose/volume/amount/turn`。`db_path` 接受 `str | pathlib.Path`；日期使用日期字符串。

- `get_index_dataset`：确保缓存覆盖后读取，缺失时可联网；`client` 为可注入的 TuShare 兼容客户端。
- `load_index_dataset`：只读本地数据库，回溯最多600个交易日作为预热；结果可能包含请求起点之前的行，且不会补齐数据库没有的历史。
- `turnover_policy="require"` 要求真实换手率；`"volume_proxy"` 在内存中改为成交量/20日均量，是明确的研究偏离。
- `DEFAULT_DB_PATH` 指向策略目录的 `data/hy_sae_timing.duckdb`，与启动目录无关。

## 训练与输出

`SAETimingGenerator(config=None)` 默认创建 `ResearchConfig()`，自身不做数据读写。

| 方法 | 返回 | 用途 |
|---|---|---|
| `run(quotes)` | `ResearchResult` | 年度扩展训练和完整样本外预测 |
| `generate(quotes, start_date=None, end_date=None)` | `pd.Series` | 先重新训练并生成完整信号，再裁剪返回日期；名称为 `HY_SAE` |
| `select_sparsity_weight(quotes, candidates=(0.001, 0.01, 0.1, 1.0))` | `(float, pd.DataFrame)` | 仅在首折训练集比较候选；选择平均激活≤2ρ的最小权重，无候选达标时报错 |

`quotes` 必须含完整训练历史和所需预热；不能只传测试区间。候选稀疏权重须非空、唯一且升序。选择函数返回权重，不会修改不可变配置。

| ResearchResult 字段 | 内容 |
|---|---|
| `predictions` | `(datetime, code)` 多级索引，各 seed 预测与均值 `score` |
| `folds` | 每折训练/测试日期、标签成熟边界及样本数 |
| `losses` | 每年、每 seed、每 epoch 的各项损失和激活量 |
| `preprocessors` | 按年份记录训练集的填补中位数及标准化均值、标准差 |
| `checkpoints` | 按年份与 seed 记录模型权重和标签缩放量 |
| `feature_names` | 有序特征名列表，默认92维 |

## 信号、回测和绩效

`threshold_signal(score, threshold=0.002)` 将预测转成 −1/0/1 的持仓方向，死区保留之前方向。`analyze.backtest(close, signal, mode="long_short")` 返回 vectorbt Portfolio；mode 还支持 `long_only`、`short_only`。价格和信号索引必须严格一致，价格须有限正数。

`analyze.backtest_frame(portfolio, signal)` 提取日度结果。当前 notebook 把它交给 `report_reference.annual_performance(frame, annual_days=252)` 计算分年及整体绩效：其 Sharpe 是几何年化收益/波动。`analyze.performance` 使用算术均值口径；两者数值可能不同。

`report_reference.backtest` 是另一套倒数空头收益计算，不等于原生账户；当前 notebook 没有调用它。实验写库与研报锚点验收也不是 `run()` 的自动步骤。
