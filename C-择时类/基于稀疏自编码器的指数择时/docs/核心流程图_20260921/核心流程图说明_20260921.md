## 从当前项目运行

从本策略项目目录（包含 `src/`、`notebook/` 和 `.env.example`）执行：

```bash
python -m pip install -r requirements.txt
cp .env.example .env
# 编辑 .env，填写自己的 TS_TOKEN 后启动 notebook
jupyter notebook notebook/hy_sae_timing.ipynb
```

DataFeed 是 Hugo 私有的数据访问模块，不随项目提供。不可用时，代码回退到开源 `tushare` 客户端，通过 `.env` 中的 `TS_TOKEN` 访问 TuShare Pro；已设置的环境变量优先。

Notebook 内核工作目录应为本策略目录或 `notebook/`。`get_index_dataset` 在行情覆盖不足时联网补取，数据自动写入本策略目录的 `data/hy_sae_timing.duckdb`。已有数据不随项目分发，`data/` 和本地 `.env` 不纳入 Git。需要严格离线读取时，可显式使用 `load_index_dataset`。

当前 notebook 的指数为 `000905.SH`，训练请求起点为 2005-01-01，样本外为 2020–2025。请求起点不等于实际训练起点：可用行情、特征和小波预热共同决定首个训练日。修改指数时需同步核对 `CODE`、研究配置和图表标题，并检查真实换手率与训练历史是否足够。

## 模型与统计口径

- 当前 notebook 明确使用 10 个 seed；`ResearchConfig` 模块默认值为 5 个。图中训练节点按 notebook 配置展示。
- 特征先做 256 日因果小波去噪，填补与标准化只拟合每折训练行；年度划分按标签成熟日清理边界。
- 默认标签为 `C[t+6]/C[t+1]−1`，对应 T 日信号、T+1 收盘成交；最后 6 行缺少成熟标签。
- 主回测调用 `analyze.backtest`，使用 vectorbt 原生账户与零费用。空头按持仓数量记盈亏。
- 分年绩效调用 `report_reference.annual_performance`，输入仍是原生账户结果；此处 Sharpe 为几何年化收益除以年化波动率。使用该统计函数不意味着已经改用研报倒数空头收益。
- `report_reference.backtest` 提供倒数收益对照，当前 notebook 未调用。实验存储与锚点模块仍在 `src/`，但 notebook 不自动写入实验结果，也不执行锚点验收。本项目未提供旧 CLI 脚本。

## 更新图源

[核心流程.dataflow.json](核心流程.dataflow.json) 是图源，使用 archify 的 `dataflow` 渲染器生成 HTML。在本目录运行，将下方占位路径替换为自己的 archify 安装目录：

```bash
node <archify安装目录>/bin/archify.mjs validate dataflow 核心流程.dataflow.json --quality showcase --json
node <archify安装目录>/bin/archify.mjs deliver dataflow 核心流程.dataflow.json 核心流程.html --quality showcase --json
node <archify安装目录>/bin/archify.mjs visual-check 核心流程.html --json
```

`deliver` 检查生成产物，`visual-check` 提供浏览器测量与截图；视觉效果还需查看截图确认。`核心流程.visual-check.*` 为可重新生成的本地检查产物。
